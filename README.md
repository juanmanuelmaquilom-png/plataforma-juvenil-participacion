## Importancia de Git

Git permite registrar los cambios del proyecto y revisar qué se modificó en cada momento. Además, ayuda a mantener un historial de versiones, recuperar cambios si ocurre un error, trabajar en equipo de manera organizada y facilitar el seguimiento del desarrollo del proyecto. Gracias a esto, se mejora la organización y la transparencia del trabajo realizado.
